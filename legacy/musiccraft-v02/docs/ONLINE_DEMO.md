# 在线演示

正式地址：https://musiccraft-agent-demo.spicypony68.chatgpt.site

任何拿到链接的人都能打开，无需登录、安装 Python 或启动本地服务。GitHub 仓库也已公开，组员可直接查看和克隆源码。

## 课堂操作

1. 点击「开始演示」，载入内置旋律和非真人参考占位音，查看风格改编方案。
2. 确认方案后运行演示，试听输出并收藏到演示台。
3. 点击「用我的声音唱」，解析并运行翻唱路线，再收藏结果。
4. 刷新页面，在演示台打开结果，展示版本回放和执行记录。

所有音频输出为浏览器程序合成的旋律，未处理原曲、克隆声音或调用 LLM。页面与阶段日志持续标明此边界。真实效果仍需部署项目的 GPU 服务后验证。

## 数据与源码

素材、任务及收藏保存在访问者当前浏览器的 IndexedDB，不上传到服务器、不与其他访客共享。禁止持久存储时降级为页面内存并提示，页面关闭后数据丢失。清理浏览器网站数据也会删除演示记录。

源码位于 online-demo/，支持静态托管，当前使用 Sites 发布。完整后端与模型代码仍在 musiccraft/、workers/ 和 deploy/。

本地检查覆盖两条路线、WAV、取消、重复提交、父版本不变与收藏来源；浏览器已验证刷新后收藏回放。发布状态成功。
